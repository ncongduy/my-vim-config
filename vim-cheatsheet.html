Grep & Quickfix
:grep -rn "pattern" .Grep recursively in project
:grep -rin "pattern" --include="*.py" .Grep with file filter
:vimgrep /pattern/ **/*Built-in grep (no shell needed)
:copenOpen quickfix results window
:ccloseClose quickfix window
:cn / :cpNext / prev quickfix result
:!grep -rn "pattern" .Run grep, show output only
:r !grep "pattern" fileInsert grep results into buffer

Pro tip: Combine counts with commands — 3dd deletes 3 lines, 5j moves down 5.
Netrw: Use :Explore or :e . as a built-in file tree. Press % to create a new file.
Shell: Run any shell command with :!cmd — e.g. :!python % runs current file.
Quickfix: :grep + :copen replaces fzf for most searches.
